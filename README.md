# 클리닉 운영 표준안 준수 대시보드

에이닷 영어학원 「클리닉 운영 표준안 v2.1(2026-08-07)」을 전국 81개 지점에 적용하기 위한
체크리스트 기반 준수 현황 대시보드입니다. 지점 유형(1~4)에 맞는 체크리스트로 담당자가 지점을 평가하면,
지점별·담당자별 준수율을 한눈에 확인할 수 있습니다.

## 주요 기능

- **이중 평가 체계**: 지점마다 **담당자 평가**와 **원장(지점장) 자가평가**를 별도로 입력·기록. 두 평가가 모두 있으면 평균으로 종합 준수율을 계산하고, 두 점수 차이가 15%p 이상이면 "격차 지점"으로 표시
- **대시보드**: 지점별 원장/담당자 준수율을 나란히 표시, 위험/미평가/격차 지점 현황, 담당자·유형·상태별 필터, 격차만 보기 필터, CSV 내보내기, 하단에 준수율 등급 기준 표기
- **지점 평가 입력**: 평가 주체(원장/담당자, 기본값 원장 자가평가) 선택 → 지점 유형에 맞춰 자동 구성되는 체크리스트 (공통기준 0~6 동선 29개 항목 + 유형별 추가 확인 2~3개 항목, 유형1·2는 31개 / 유형3·4는 32개)
- **지점 설정**: 지점별 담당자·유형 관리, 표에서 직접 수정 가능. **'공간 인력' 판단 엑셀을 업로드하면 지점명이 일치하는 지점의 담당자·유형이 자동으로 반영**되며, 공간O/X·인력O/X 판단 기준 설명도 화면에서 펼쳐볼 수 있음
- **지점 상세**: 담당자/원장 평가를 모두 포함한 전체 평가 이력 로그(회차별 체크리스트 결과 펼쳐보기), 역할별 준수율 추이 그래프(각 지점에 % 수치·평가일 표기), 역할별 필터 탭
- 평가를 저장할 때 그 시점의 체크리스트 문항을 함께 스냅샷으로 저장하므로, 이후 체크리스트가 개정되어도 과거 평가 로그의 항목·문구는 바뀌지 않습니다

## 준수율 등급 기준

체크리스트 통과율(통과 ÷ (통과+미흡))을 기준으로 다음과 같이 구분합니다. 표준안 문서에는 이 등급 구간에 대한 규정이 없어 대시보드 자체 기준으로 설정했습니다 — 필요시 코드의 `band()` 함수에서 조정할 수 있습니다.

| 등급 | 기준 |
|---|---|
| 우수 | 85% 이상 |
| 양호 | 70% ~ 84% |
| 위험 | 70% 미만 |
| 미평가 | 평가 기록 없음 |
| 평가 격차 경고 | 원장·담당자 점수 차이 15%p 이상 |

## 실행 방법

별도 설치나 빌드 없이 순수 HTML/CSS/JS로 작성되었습니다.

1. 저장소를 내려받거나 클론합니다.
2. `index.html`을 브라우저로 엽니다. (또는 GitHub Pages로 배포)

### GitHub Pages로 배포하기

1. 이 저장소를 GitHub에 푸시합니다.
2. **Settings → Pages**에서 배포 브랜치를 `main`, 폴더를 `/ (root)`로 설정합니다.
3. `https://<사용자명>.github.io/<저장소명>/`으로 접속하면 대시보드가 열립니다.

## 데이터 저장 방식

이 대시보드는 **연결된 구글 시트를 공용 저장소로 사용**합니다. `index.html` 상단의 `APPS_SCRIPT_URL` 상수에 배포된 Google Apps Script 웹앱 주소가 설정되어 있으면, Claude.ai 아티팩트로 열든 GitHub Pages로 열든 **동일한 구글 시트에 저장·조회**되어 모든 기기·모든 사용자에게 데이터가 공유됩니다.

| 조건 | 저장 위치 | 공유 여부 |
|---|---|---|
| `APPS_SCRIPT_URL` 설정됨 (현재 상태) | 연결된 구글 시트 | ✅ 모든 환경·모든 사용자에게 공유 |
| `APPS_SCRIPT_URL` 비어있음 + Claude.ai 아티팩트 | Claude 공유 저장소 | ✅ Claude 접근 권한자에게 공유 |
| `APPS_SCRIPT_URL` 비어있음 + 그 외 환경 | 브라우저 `localStorage` | ❌ 이 브라우저에만 저장 |

구글 시트 백엔드를 직접 설정하려면(또는 다른 시트로 교체하려면) `apps-script-storage-backend.gs`의 코드를 Google Sheets의 확장 프로그램 → Apps Script에 붙여넣고 웹앱으로 배포한 뒤, 그 URL을 `index.html`의 `APPS_SCRIPT_URL`에 넣으면 됩니다.

### 관리자 전용 삭제 도구 (비공개)

평가 기록 삭제는 이 저장소에 포함되어 있지 않습니다. 별도의 `admin-tool.html`(비밀번호로 보호된 삭제 전용 도구)을 통해서만 가능하며, **이 파일은 절대 이 공개 저장소에 커밋하지 마세요** — GitHub 저장소가 Public이라 코드를 누구나 볼 수 있고, 관리자 비밀번호 확인 로직 자체는 안전하지만 도구 파일을 공개하면 삭제 기능의 존재와 사용법이 노출됩니다. 본인 컴퓨터에만 보관하세요.

## 지점 유형 안내

| 유형 | 여건 | 목표 | 테스트존 | 지정좌석제 |
|---|---|---|---|---|
| 유형 1 | 공간 O / 인력 O | 관리 품질 극대화 | 클리닉 공간 내 | 불필요 |
| 유형 2 | 공간 X / 인력 O | 회전율 확보 | 클리닉실 인접 | 불필요 |
| 유형 3 | 공간 O / 인력 X | 시스템 기반 운영 | 데스크 | 필수 |
| 유형 4 | 공간 X / 인력 X | 최소 기준 붕괴 방지 | 데스크 | 필수 |

지점 유형은 기본값이 "미지정"이며, **지점 설정** 탭에서 '공간 인력' 판단 엑셀을 업로드해 일괄 반영하거나 표에서 직접 지정해야 해당 지점의 체크리스트가 표시됩니다.
