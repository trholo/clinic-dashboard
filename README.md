# 클리닉 운영 표준안 준수 대시보드

에이닷 영어학원 「클리닉 운영 표준안 v2.1(2026-08-07)」을 전국 81개 지점에 적용하기 위한
체크리스트 기반 준수 현황 대시보드입니다. 지점 유형(1~4)에 맞는 체크리스트로 담당자가 지점을 평가하면,
지점별·담당자별 준수율을 한눈에 확인할 수 있습니다.

## 주요 기능

- **이중 평가 체계**: 지점마다 **담당자 평가**와 **원장(지점장) 자가평가**를 별도로 입력·기록. 두 평가가 모두 있으면 평균으로 종합 준수율을 계산하고, 두 점수 차이가 15%p 이상이면 "격차 지점"으로 표시
- **대시보드**: 지점별 원장/담당자 준수율을 나란히 표시, 위험/미평가/격차 지점 현황, 담당자·유형·상태별 필터, 격차만 보기 필터, CSV 내보내기, 하단에 준수율 등급 기준 표기
- **지점 평가 입력**: 평가 주체(담당자/원장) 선택 → 지점 유형에 맞춰 자동 구성되는 체크리스트 (공통기준 0~6 동선 29개 항목 + 유형별 추가 확인 2~3개 항목, 유형1·2는 31개 / 유형3·4는 32개)
- **지점 설정**: 지점별 담당자·원장(지점장)·유형 관리 (담당자 변경 이력 반영 가능)
- **지점 상세**: 담당자/원장 평가를 모두 포함한 전체 평가 이력 로그(회차별 체크리스트 결과 펼쳐보기), 역할별 준수율 추이 그래프(각 지점에 % 수치 표기), 역할별 필터 탭
- 평가를 저장할 때 그 시점의 체크리스트 문항을 함께 스냅샷으로 저장하므로, 이후 체크리스트가 개정되어도 과거 평가 로그의 항목·문구는 바뀌지 않습니다

## 준수율 등급 기준

체크리스트 통과율(통과 ÷ (통과+미흡))을 기준으로 다음과 같이 구분합니다. 표준안 문서에는 이 등급 구간에 대한 규정이 없어 대시보드 자체 기준으로 설정했습니다 — 필요시 코드의 `band()` 함수에서 조정할 수 있습니다.

| 등급 | 기준 |
|---|---|
| 우수 | 85% 이상 |
| 양호 | 70% ~ 84% |
| 위험 | 70% 미만 |
| 미평가 | 평가 기록 없음 |
| 평가 격차 경고 | 원장·담당자 점수 차이 15%p 이상 |

## 실행 방법

별도 설치나 빌드 없이 순수 HTML/CSS/JS로 작성되었습니다.

1. 저장소를 내려받거나 클론합니다.
2. `index.html`을 브라우저로 엽니다. (또는 GitHub Pages로 배포)

### GitHub Pages로 배포하기

1. 이 저장소를 GitHub에 푸시합니다.
2. **Settings → Pages**에서 배포 브랜치를 `main`, 폴더를 `/ (root)`로 설정합니다.
3. `https://<사용자명>.github.io/<저장소명>/`으로 접속하면 대시보드가 열립니다.

## ⚠ 데이터 저장 방식 (중요)

이 도구는 원래 Claude.ai 아티팩트의 공유 저장소(`window.storage`) 기반으로 만들어졌습니다.
Claude.ai 밖(예: GitHub Pages, 로컬 파일 실행)에서는 해당 API가 없기 때문에,
**브라우저의 `localStorage`로 자동 폴백**하도록 구성해두었습니다.

| 실행 환경 | 저장 위치 | 담당자 간 공유 여부 |
|---|---|---|
| Claude.ai 아티팩트 | Claude 공유 저장소 | ✅ 자동 공유 |
| GitHub Pages / 로컬 실행 | 접속한 브라우저의 `localStorage` | ❌ 이 브라우저에만 저장, 공유 안 됨 |

즉, GitHub Pages로 배포한 버전은 **각자의 브라우저에만 데이터가 남기 때문에, 6명의 담당자가 같은
화면을 봐도 평가 데이터는 공유되지 않습니다.** 여러 담당자가 함께 입력하고 같은 데이터를 보려면
다음 중 한 가지 방식으로 공용 백엔드를 연결하는 작업이 추가로 필요합니다.

- Firebase Realtime Database / Firestore
- Google Sheets API (Apps Script 웹앱)
- 간단한 자체 백엔드(Supabase, Cloudflare Workers + KV 등)

현재는 각 담당자가 **개인 PC에서 평가를 입력 → CSV 내보내기 → 취합**하는 방식으로 임시 운영하거나,
Claude.ai 아티팩트 버전을 함께 쓰는 방식을 권장합니다.

## 지점 유형 안내

| 유형 | 여건 | 목표 | 테스트존 | 지정좌석제 |
|---|---|---|---|---|
| 유형 1 | 공간 O / 인력 O | 관리 품질 극대화 | 클리닉 공간 내 | 불필요 |
| 유형 2 | 공간 X / 인력 O | 회전율 확보 | 클리닉실 인접 | 불필요 |
| 유형 3 | 공간 O / 인력 X | 시스템 기반 운영 | 데스크 | 필수 |
| 유형 4 | 공간 X / 인력 X | 최소 기준 붕괴 방지 | 데스크 | 필수 |

지점 유형은 최초 배포 문서에 지점별로 명시되어 있지 않아 기본값은 "미지정"입니다.
**지점 설정** 탭 또는 평가 입력 시 유형을 지정해야 해당 지점의 체크리스트가 표시됩니다.
